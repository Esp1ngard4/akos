# Notebooks

Top-level landing page. Notebooks are organized into six fixed categories. This page does not change per-notebook — see each category's own index for its notebooks.

| Category | Description | Index |
|---|---|---|
| Diary | Single flat notebook for reflections, memories, ideas and ad-hoc personal capture. There is only ever one. | [diary/index.md](diary/index.md) |
| Projects | Registry of project-scoped notebooks — one per active project (has an end state). | [projects/index.md](projects/index.md) |
| Area of Focus | Registry of area-of-focus-scoped notebooks — one per ongoing area of responsibility. | [areaOfFocus/index.md](areaOfFocus/index.md) |
| Area of Interest | Registry of area-of-interest-scoped notebooks — one per deep-dive/thematic topic of ongoing interest (no end state, not a responsibility). | [areaOfInterest/index.md](areaOfInterest/index.md) |
| Meetings | Flat registry of all meeting notes — one file per meeting, optionally cross-referenced to a project/area-of-focus/area-of-interest notebook. | [meetings/index.md](meetings/index.md) |
| eDiary | Flat registry of crystallized diary posts — one static HTML file per post, each required to cross-reference the single raw capture entry it was drafted from. | [eDiary/index.md](eDiary/index.md) |
